# 一、表情/情绪分析系统信息表
| 项目 | 详细说明 |
| :--- | :--- |
| 系统名称 | 基于YOLO的表情/情绪分析系统 |
| 核心算法 | YOLO目标检测模型（表情识别） |
| 大模型支持 | 接入DeepSeek、Qwen等大模型，提供AI分析建议 |
| 识别情绪类别 | Angry（愤怒）、Confused（困惑）、Happy（开心）、Neutral（中性）、Sad（悲伤） |
| 检测模式 | 图片检测、批量图片检测、视频检测、摄像头实时检测 |
| 输出内容 | 情绪识别结果、置信度、耗时、检测图像、AI分析报告 |
| 管理功能 | 识别记录查询/删除、用户管理、数据统计看板 |
| 界面特点 | 简洁直观的后台管理界面，操作流程简单 |
| 适用对象 | 企业、研究机构、教育机构、服务行业等 |

---

## 二、系统核心功能清单
| 功能模块 | 详细描述 |
| :--- | :--- |
| 单张图片检测 | 上传单张图片，实时输出情绪类别、置信度，生成标注结果图 |
| 批量图片检测 | 上传图片文件夹，批量识别并生成表格结果，支持预览和导出 |
| 视频文件检测 | 上传视频文件，逐帧识别情绪，生成检测视频和统计结果 |
| 摄像头实时检测 | 调用本地摄像头，实时识别画面中人物情绪，动态展示结果 |
| AI分析报告 | 接入DeepSeek/Qwen等大模型，基于识别结果生成情绪解读和场景建议 |
| 数据统计看板 | 展示不同情绪识别数量、用户识别统计、近十日识别趋势等可视化图表 |
| 识别记录管理 | 支持按时间/结果查询历史记录，查看原图与结果对比，支持删除 |
| 用户权限管理 | 支持多用户登录、账号注册/密码找回、个人中心管理 |

## 三、核心优势
- **识别快速准确**：基于YOLO模型优化，识别效率高、情绪分类准确率高
- **多场景适配**：支持图片/视频/摄像头/批量检测，满足不同使用场景需求
- **结果展示直观**：标注结果图、表格数据、统计图表多维度展示识别结果
- **AI赋能分析**：大模型辅助解读情绪，提供场景化建议，提升报告专业性
- **操作简单易上手**：界面简洁，流程清晰，无需复杂配置即可使用

# 四、应用场景
1.  **市场调研与用户反馈**
    采集用户对产品、广告的面部表情，分析用户情绪倾向，优化产品设计和营销方案。
2.  **客户服务质量监控**
    客服通话/视频中识别客户情绪，及时发现不满情绪，辅助客服人员调整沟通策略。
3.  **教育与心理辅导**
    课堂上分析学生情绪状态，了解学习专注度和心理状态，辅助教师开展个性化教学。
4.  **安全与安防监控**
    公共场合识别异常情绪（如愤怒、焦虑），提前预警潜在冲突风险。
5.  **影视/游戏用户体验测试**
    分析用户观看视频、体验游戏时的情绪反应，优化内容设计和交互体验。
6.  **学术研究**
    心理学、社会学、人机交互等领域的情绪相关实验数据采集与分析。
